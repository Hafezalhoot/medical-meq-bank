# Phase B2 — Safer, faster lecture intake

> For implementers: follow test-driven development and verification-before-completion.

## Goal
Keep personal lecture intake review-first while reducing repeated typing. Let a selected local PDF fill its **filename only**, and reopen metadata drafts downloaded from Manage Library. Never upload a PDF, publish medical content automatically, or touch ratings.

## Scope
- Native source-PDF picker; no byte reads or upload. Editable filename and suggested title/ID.
- Native JSON file picker accepting only the existing v1 metadata-only intake format.
- Imported draft must pass course, specialty, chapter, title, source, ID, order, topics and duplicate checks before any form value is replaced.
- Session-only recovery remains; downloadable draft provides durable cross-session recovery.
- Everything still requires original PDF review and tested GitHub publication workflow.
