# Medical MEQ Review Bank

Private source repository for the Medical MEQ & Short Question Review Bank.

The project is an offline-first Progressive Web App (PWA) containing lecture-based MEQ cases, high-yield short questions, image/spot questions, detailed practice, rapid recall, saved progress, dark mode, and two-level lecture/subtopic navigation.

## Current Urology lectures

1. Congenital Anomalies
2. BPH & Prostate Carcinoma

## Local use

Open `index.html` through a local web server so the service worker can run. The standalone file in `offline/` can be opened directly without a server.

## Privacy

The repository is private. Deployment access is configured separately from repository visibility.
